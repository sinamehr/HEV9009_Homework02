# AI-adoption metadata and graph workflow

This coursework subproject is a small, self-contained example drawn from the wider Paper 003 project. It demonstrates version-controlled scientific coding, reproducible reporting, and clear separation of data, code, figures, and documentation.

The repository includes a fake metadata sample, an R visualization script, its graph output, and a Quarto report. These materials represent only a limited teaching example, not the full research project or its data.

Detailed explanations of the sample, visualization, graphical grammar, and reproducibility scope are provided in `report.qmd`.

## Render locally

With Quarto installed, run:

```bash
quarto render report.qmd
```

R is required only to run the included visualization script with its dependencies and inputs. The repository is local; no remote publication or collaboration workflow is configured.
